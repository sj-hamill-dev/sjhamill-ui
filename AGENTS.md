## Before doing anything

1. Read [`CLAUDE.md`](CLAUDE.md).
2. Read `../sjhamill-archives/REPO_CLEANUP_PLAYBOOK.md` and `../sjhamill-archives/agent-context/AGENT_ISSUE_FILING.md` if you're doing repo-hygiene work.

## Behavior rules

1. **`CLAUDE.md` wins** for anything about what the repo does or how it's consumed.
2. **This is a library, not a service.** No deploys, no runtime env, no ADC / GCP auth. If a task mentions Cloud Run, Cloud Functions, BigQuery, or service accounts, you're in the wrong repo.
3. **Every commit to `main` ships to 3 downstream Cloudflare Pages apps within 6h** via each consumer's `sync-sjhamill-ui.yml`. Land risky changes on a branch and coordinate before merge.
4. **Don't casually refactor these three surfaces — they're load-bearing for every consumer:**
   - `tailwind-preset.js` (all 3 consumers import it directly)
   - `src/styles/globals.css` (the `--*` CSS-var contract; renaming a token silently breaks Tailwind classes downstream)
   - `src/lib/utils.ts` exported names (`cn`, `formatCurrency`, `TABLEAU_10`, `COST_TYPE_COLORS`, `STATUS_COLORS`)
5. **Components are currently unused by all 3 consumers.** Safer to refactor than 1–3 above, but `grep -r "@sjhamill/ui" ../procore-direct-costs-app/src ../procore-direct-costs-embed-app/src ../vendor-analytics-app/src` before renaming exports from `src/index.ts`.
6. **Do NOT touch without an explicit ask:**
   - `ds-bundle/`, `.ds-sync/` — generated by the design-sync converter. Hand-edits are lost on next re-sync.
   - `.design-sync/` — cross-Claude-account collaboration config. Owned by the design-sync workflow.
   - `.specstory/` — deprecated session transcripts. Never read, list, or reference. Burns tokens for zero value.
   - `.github/workflows/*.yml` — coordinate CI changes.
7. **No published npm package.** Consumers install via `git+https://…sjhamill-ui.git#main`. Never suggest `npm publish` or GitHub Packages workflows.
8. **`peerDependencies` (`react`, `react-dom`, `tailwindcss`) stay peer.** Moving them to `dependencies` duplicates React in the consumer and breaks hooks.

## Issue filing

This repo does **not** have auto-add enabled on Project #2. Use the two-step pattern:

```powershell
$url = gh issue create --repo sj-hamill-dev/sjhamill-ui --title "..." --body "..."
gh project item-add 2 --owner sj-hamill-dev --url $url
```

Style rules: imperative titles, ≤80 chars, sentence case, no trailing period. Body: what/why + relevant paths + `Priority: NOW|NEXT|LATER`. Full guide: `../sjhamill-archives/agent-context/AGENT_ISSUE_FILING.md`.
